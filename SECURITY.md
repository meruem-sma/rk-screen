# Security reporting

Report suspected vulnerabilities privately to rksoftworks@gmail.com. Include the affected version, reproduction steps and a minimal example without passwords, personal files or session data. Do not exploit other people's devices. General bugs may be reported in GitHub issues.

The maintainer reviews reports; no fixed response-time commitment or completed independent audit is claimed. Current security boundaries and known production gaps are documented in [GUVENLIK-MODELI.md](GUVENLIK-MODELI.md). Beta 1 is unsigned and may be blocked by Windows Smart App Control.
